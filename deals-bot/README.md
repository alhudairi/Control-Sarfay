# بوت العروض 🛒

بوت تليجرام ينشر عروض المتاجر في قناتك برابط العمولة حقك.
يدعم **أمازون، نون، تيمو، شي إن، علي إكسبريس، نمشي**، وأي متجر ثاني.

## طريقة الاستخدام

1. افتح محادثة خاصة مع البوت.
2. أرسل **صورة المنتج** ومعها وصف، كل معلومة في سطر:

   ```
   https://www.noon.com/saudi-ar/...
   سماعة سوني WH-1000XM5 لاسلكية
   1499
   999
   كود الخصم: SAVE10
   ```

   | السطر | المحتوى |
   |---|---|
   | ١ | رابط المنتج (شوف الجدول اللي تحت) |
   | ٢ | اسم المنتج |
   | ٣ | السعر قبل الخصم |
   | ٤ | السعر بعد الخصم |
   | ٥ | ملاحظة (اختياري) |

3. البوت يرجّع لك المنشور جاهز، وفيه اسم المتجر ونسبة الخصم محسوبة.
4. اضغط **✅ انشر في القناة** أو **❌ إلغاء**.

إذا المنتج انتشر قبل، البوت ينبهك ويعطيك السعر وتاريخ النشر السابق.

## أي رابط أحط؟

| المتجر | الرابط |
|---|---|
| **أمازون** | أي رابط للمنتج، حتى المختصر مثل `amzn.to`. البوت يحذف أي كود عمولة موجود ويحط كودك (`AMAZON_TAG`) |
| **نون، تيمو، شي إن وغيرها** | **رابط العمولة** اللي تطلّعه من لوحة برنامج العمولة حق المتجر. البوت ينشره بدون أي تعديل |

> ⚠️ إذا نسخت رابط نون أو تيمو العادي من المتصفح بدل رابط العمولة، **ما تجيك عمولة**.
> كل متجر يطلّع روابط العمولة من لوحته الخاصة، وبعضها روابط مختصرة لها رقم خاص فيك.

متاجر غير اللي في القائمة تشتغل عادي. بس المنشور يكتب "اطلبه الآن" بدل اسم المتجر.

## الإعداد

### ١. بوت تليجرام
1. كلّم **@BotFather** في تليجرام، اكتب `/newbot`، واحفظ الـ **Token**.
2. أضف البوت في قناتك **كمشرف** وأعطه صلاحية **نشر الرسائل**.

### ٢. برامج العمولة
- **أمازون السعودية:** من لوحة [Amazon Associates](https://affiliate-program.amazon.sa) انسخ **Tracking ID**، وغالباً ينتهي بـ `-21`.
- **نون وتيمو وغيرها:** سجّل في برنامج العمولة حق كل متجر، ومن لوحته طلّع رابط المنتج.

### ٣. ملف الإعدادات
انسخ `.env.example` إلى ملف اسمه `.env` وعبّي القيم:

| المتغير | الوصف |
|---|---|
| `TELEGRAM_BOT_TOKEN` | التوكن من BotFather |
| `TELEGRAM_CHANNEL_ID` | `@اسم_القناة` أو رقمها |
| `ADMIN_USER_IDS` | رقم حسابك في تليجرام. شغّل البوت وأرسل له `/start` وبيعطيك الرقم |
| `AMAZON_TAG` | كود التتبع حق أمازون. تحتاجه بس إذا بتنشر من أمازون |
| `DISCLOSURE` | سطر الإفصاح أسفل كل منشور. خلّه بين علامتي تنصيص `"..."` |

⚠️ **لا ترفع ملف `.env` على GitHub ولا ترسله لأحد.** الملف مستثنى تلقائياً من git.

### ٤. التشغيل
يحتاج **Node.js 20.6 أو أحدث**، وما يحتاج تثبيت أي مكتبات.

```bash
cd deals-bot
npm start
```

أول مرة: خلّ `ADMIN_USER_IDS` فيه أي رقم مؤقت، وشغّل البوت، وأرسل له `/start` عشان يعطيك رقم حسابك. حط الرقم في `.env` وأعد التشغيل.

## وين أشغّله؟

البوت لازم يكون شغّال طول الوقت عشان يستقبل رسائلك:

- **سيرفر سحابي** (الأفضل): Railway أو Render أو أي VPS. حط المتغيرات في إعدادات **Environment Variables** في المنصة بدل ملف `.env`، وخلّ أمر التشغيل `node src/index.js`.
  سجل المنتجات المنشورة محفوظ في `data/posted.json`. إذا المنصة تمسح الملفات مع كل تحديث، أضف لها **Volume** على مجلد `data`.
- **من جوالك عن طريق Termux**: ينفع للتجربة، لكن البوت يوقف إذا أندرويد قفل التطبيق في الخلفية.

## إضافة متجر جديد

أضف سطر في قائمة `STORES` في الملف `src/stores.js`. فيه اسم المتجر بالعربي والدومين حقه:

```js
{ id: 'ounass', name: 'أُناس', hosts: ['ounass.sa'] },
```
